# 📊 أداة متابعة مشتريات المشروع

أداة ويب احترافية لمتابعة مشتريات مشروع **بنك المنشآت الصغيرة والمتوسطة** — تطوير الهوية البصرية للبيئة الداخلية.

## ✨ الميزات

- 📱 **واجهة استجابية** تعمل على الجوال والحاسوب
- 🔄 **مزامنة فورية** بين جميع أعضاء الفريق
- 📈 **تتبع التقدم** مع رسوم بيانية ونسب إنجاز
- 👥 **تعيين المسؤولين** لكل بند (بدر، ريان، سليمان)
- 🎯 **فلاتر متقدمة** للبحث والتصفية
- 💾 **حفظ تلقائي** — لا تقلق بشأن فقدان البيانات
- 🔐 **رابط مشترك آمن** — شارك الرابط مع الفريق فقط

## 🚀 كيفية الاستخدام

### الخطوة الأولى: فتح الأداة
1. انتقل إلى الملف `index.html` واضغط على الزر:
   ```
   إنشاء قاعدة بيانات مشتركة
   ```

### الخطوة الثانية: شارك الرابط
- سيظهر رابط جديد — **انسخه تماماً كما هو**
- شاركه مع الفريق (بدر، ريان، سليمان)
- **نفس الرابط = نفس البيانات للجميع**

### الخطوة الثالثة: ابدأ العمل
- اختر اسمك من القائمة
- ضع علامة صح (✓) على كل بند تم شراؤه
- عين المسؤول عن كل بند
- كل التعديلات تحفظ تلقائياً

## 📋 المراحل الثلاث

### المرحلة الأولى: تجهيزات المبنى بالهوية البصرية
- 12 بند
- القيمة الإجمالية: ~147,400 ريال

### المرحلة الثانية: تجهيزات مكتب الرئيس وغرفة الاجتماعات
- 29 بند
- القيمة الإجمالية: ~130,000 ريال

### المرحلة الثالثة: اللوحات الخارجية للمبنى
- 8 بنود
- القيمة الإجمالية: ~215,000 ريال

## 🎨 التصميم

- **نظام ألوان احترافي** يعكس هوية البنك
- **واجهة سهلة الاستخدام** مع تجربة سلسة
- **أيقونات وعلامات توضيحية** لسهولة الفهم
- **حساسة للغة العربية** مع دعم كامل للاتجاه من اليمين لليسار

## 🔧 التقنيات المستخدمة

- **HTML5** للهيكل الأساسي
- **CSS3** للتصميم المتقدم والاستجابة
- **JavaScript Vanilla** بدون مكتبات خارجية
- **JSON Storage API** لحفظ البيانات المشتركة

## 📝 ملاحظات مهمة

✅ البيانات تحفظ تلقائياً كل 500 ملي ثانية  
✅ يمكنك فتح الأداة من عدة نوافذ في نفس الوقت  
✅ اضغط "تحديث" لسحب أحدث التغييرات من الفريق  
✅ لا توجد حدود على عدد المستخدمين المتزامنين  

## 📞 للمساعدة

إذا واجهت أي مشكلة:
1. حاول تحديث الصفحة (F5)
2. امسح ذاكرة التخزين المؤقت (Cache)
3. تأكد من اتصالك بالإنترنت
4. جرب من متصفح مختلف
